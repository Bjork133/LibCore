libcore — CLI-ядро для управления физической библиотекой.

ИСПОЛЬЗОВАНИЕ:
    libcore [ГЛОБАЛЬНЫЕ ФЛАГИ] <КОМАНДА> [АРГУМЕНТЫ] [ФЛАГИ]
    libcore help [ЧТО-УГОДНО]

ГЛОБАЛЬНЫЕ ФЛАГИ:
    --json, --gui       Вывод в машиночитаемом JSON
    -q, --quiet         Меньше вывода
    -v, --verbose       Больше вывода
    -V, --version       Показать версию
    -h, --help          Показать справку

ХЕЛПЫ:
    Хелпы — это просто .txt-файлы в ~/.config/libcore/help/.
    Имя файла — команда без пробелов, в нижнем регистре.
    libcore help book add   →  ~/.config/libcore/help/bookadd.txt
    Можно добавлять свои хелпы — программа не проверяет,
    существует ли команда.
