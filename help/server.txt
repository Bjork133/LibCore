libcore server — управление сервером библиотеки.

ИСПОЛЬЗОВАНИЕ:
    libcore server <ПОДКОМАНДА> [АРГУМЕНТЫ] [ФЛАГИ]

ПОДКОМАНДЫ:
    init [--name N] [--host U] [--port P]   Создать библиотеку
    list                                     Список библиотек на машине
    code [NAME]                              Показать код подключения
    status [NAME]                            Сводка по библиотеке
    start [NAME] [--port P]                  Запустить HTTP-сервер (LAN)

За подробностями: libcore help server <ПОДКОМАНДА>
